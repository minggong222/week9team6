## 사용한 원본 타일

다운로드의 kenney_3d-road-tiles.zip에서 필요한 원본 OBJ·MTL과 License.txt를 보존한다.

| 원본 | 용도 |
|---|---|
| roadTile_163 | 잔디 줄과 배경 바닥 |
| roadTile_034 | 넓은 도로의 중앙 아스팔트 |
| roadTile_059 | 좁은 도로 양쪽 / 넓은 도로의 양쪽 경계 |
| roadTile_002 | 출발·도착 광장, 좌우 보행로 |
| roadTile_019, roadTile_020 | 좌우 가장자리 나무 2종 |

원본의 3×3유닛 바닥을 2/3 배율로 맞춘다. 타일의 원본 면·UV·법선을 유지해 줄이나 구간 단위의 OBJ로 조립한다. 원본 재질 색은 4×4 컬러 텍스처로 옮겨 자동차의 컬러맵과 같은 색 변환 경로를 사용한다. 경사·다리·터널은 사용하지 않았다. roadTile_075 횡단보도는 후보로만 남겨두었고 이번 기본 배치에는 넣지 않았다.

## 생성 파일

모든 경로는 Assets/Models/Crossy/RoadTiles 아래다.

- kenney-grass-row.obj: 잔디 23타일을 합친 46×2유닛 줄.
- kenney-plaza-row.obj: 중앙 보도 7타일과 주변 잔디를 합친 줄.
- kenney-road-narrow.obj: roadTile_059 두 줄로 구성한 46×4유닛 도로.
- kenney-road-wide.obj: 059 + 034 + 059 세 줄로 구성한 46×6유닛 도로.
- kenney-sidewalk.obj: 보도 40타일을 합친 80×2유닛 보행로.
- kenney-backdrop.obj: roadTile_163으로 만든 낮은 배경 바닥.
- kenney-map.mtl: Kd=1과 재질별 컬러 텍스처를 연결한다.
- kenney-color-*.png: 원본 Grass·Asphalt·Stone·Alternate_Dirt·FrontColor 색상의 4×4 텍스처.
- kenney-tree-019.obj / kenney-tree-020.obj: 원본 나무 형상을 유지하고 kenney-map.mtl을 참조한다.

추가 텍스처 다운로드는 필요 없다. 별도 LaneMark 액터나 직접 만든 차선 텍스처도 사용하지 않는다. 자동차·바위·벤치·콘은 이전에 가져온 에셋을 유지한다.

## 다시 생성하기

프로젝트 루트에서 Node.js로 실행:

```text
node Tools/GenerateCrossyRoad.mjs
```

도로 위치와 폭은 스크립트의 roadStarts / roadWidths에서 설정한다. 이 스크립트는 생성한 지형·나무를 다시 배치하고 자동차 X 좌표를 조정한다. Player와 카메라 및 다른 이름의 추가 액터는 유지한다. 생성한 지형의 배치를 에디터에서 바꿨다면 재실행 전에 씬을 복사해 둔다.

## 플레이어와 확인할 부분

Player의 DefaultSceneRoot 아래에 메시와 카메라를 각각 연결한다. Hitori 메시 Yaw=180, 카메라 상대 위치 (-8,0,10), Pitch=40을 유지했다.

사용자가 재빌드 후 에디터에서 Crossy.scene을 다시 열고 Play로 확인한다. 이번 맵 변경에 대한 에디터 실행·플레이 테스트는 수행하지 않았다. 파일 구조·에셋 참조만 확인했다.

현재 이동은 기존 WASD 연속 이동이다. 자동차 이동, 격자 이동, 좌우 경계 제한, 충돌 사망, 점수, 도착 판정은 연결하지 않았다. 바닥과 장식의 충돌은 꺼져 있다.

## 도로·잔디 색상 처리 수정

현재 Forward(UberLit)와 Deferred(GBuffer) 셰이더는 이미지 RGB에 pow(color,2.2)를 적용한 뒤 BaseColor를 곱한다. 자동차는 컬러맵 이미지에 색이 들어 있고 BaseColor=1이지만, 기존 맵은 흰 텍스처에 Kd 색을 곱해 서로 다른 색 변환을 거쳤다. 맵도 원본 Kd 색을 컬러 텍스처에 넣고 Kd=1로 바꿔 자동차와 같은 경로를 사용한다. 전역 셰이더·조명 수치는 바꾸지 않았다.

OBJ.bin은 파일 변경 시간 검사 없이 로드되므로, 생성한 맵과 나무의 캐시만 다시 생성하도록 제거한다. 에디터를 완전히 종료하고 다시 실행해야 메모리의 기존 재질도 새로 읽힌다.

씬 배치 없이 맵 재질·메시만 다시 생성할 때:

```text
node Tools/GenerateCrossyRoad.mjs --assets-only
```

이번 색상 수정은 실행 테스트하지 않았다. 사용자가 실행 화면에서 확인한다.
